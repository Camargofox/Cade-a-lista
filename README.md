# Cadê a Lista?

> 🌐 **Acesse o projeto em produção:** [cadealista.netlify.app](https://cadealista.netlify.app)

**Cadê a Lista?** é a solução para um dos problemas mais chatos do dia a dia: gerenciar listas de compras de forma prática. Cansado de ficar editando e se perdendo nas mensagens de texto do WhatsApp? É exatamente para resolver isso que o projeto nasceu!

Com ele, você cria, organiza e gerencia seus itens em tempo real, direto no navegador.

---

## Funcionalidades

* **Adição Dinâmica:** Insira novos itens na tabela instantaneamente sem precisar recarregar a página.
* **Interface Responsiva:** O layout se adapta ao tamanho da tela e conta com rolagem inteligente (`overflow`) para listas muito grandes.
* **Estilização Exclusiva:** Botões e elementos customizados via CSS para uma melhor experiência visual.

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando o trio fundamental do Front-end:

* **HTML5:** Estruturação semântica da página e tabelas.
* **CSS3:** Estilização moderna, layout responsivo e controle de containers com scroll.
* **JavaScript (Vanilla):** Manipulação dinâmica do DOM (`document.createElement`, capturas de inputs e eventos).
